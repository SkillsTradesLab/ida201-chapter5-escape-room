# IDA201 Motors & Controls — Chapter 5 Escape Room

Interactive classroom escape room covering Components, Symbols & Circuitry.

## Game structure
- 5 rooms
- 25 questions total
- Short-answer first
- Incorrect first attempt converts the question to multiple choice
- First-try score and elapsed time
- Final 5-digit escape code

## GitHub Pages
1. Open **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/root**.
4. Save.

The student-facing site is hosted from the neutral `SkillsTradesLab` account.
